# ColorShift — Full GDD

Full design document for **ColorShift**, Atomic Lemon Studio's game for GitHub Game Off 2026 (theme: *Shift*). The summary is in the [one-page GDD](https://github.com/IES-Rafael-Alberti/gameoff2026-atomiclemonstudio/blob/main/GDD.md).

> **The GDD rules.** This document is the reference for the whole team. Issues carry out what is decided here; they don't decide it. If something changes, it changes in the GDD first and in the issues afterwards.

> Legend: _(proposal)_ = suggested, awaiting confirmation. _(out of scope)_ = only if there is time left. _(pending)_ = not decided yet. _Team debate_ = the team settles it.
